Hva skal vi bruke i dag? 🛠️

MakeCode / micro:bit / bit:bot ⚡

  1. 🏎️ Vi skal kode bilen til å følge en linje!
  2. 🏎️ Vi skal kontrollere bilen med en kontroller over radio!
  • 🧩 Husk at formen på blokkene kan hjelpe deg med å se hvordan de passer sammen.

Overføre koden til micro:bit 🔌

Når blokkene er lagt opp kan du overføre koden til micro:bit.

1. Koble til USB-ledningen 🔌

Plugg USB A-ledningen inn i PC-en og micro-USB-enden i micro:biten. Pass på å setter ledningen forsiktig og riktig vei!

2. Last ned og sammenkoble (Pair) 📥

Trykk knappen "Last ned", "Neste" og "Pair" i MakeCode, deretter "Last ned". (Alternativt: flytt fila manuelt over).

3. Sett i Bitbot 🏎️

Set micro:bit inn i bitbot-bilen. ⚠️ Husk at bilen bør være avslått før du setter den inn.

Dagens første oppgave: Følg linjen! 🎯

1. Åpne nettleseren på PC-en din 🌐
2. Gå inn på https://makecode.microbit.org 🔗
3. Opprett et nytt prosjekt (kall det hva du vil) ➕
4. Legg til utvidelsen: Bitbot 📦
5. Sett opp blokkene slik at bilen følger linjen! 🏎️💨

Løsningsforslag (Kode) 💻

bitbot.select_model(BBModel.XL)
basic.forever(function () {
    if (bitbot.readLine(BBLineSensor.Left) == 1 && bitbot.readLine(BBLineSensor.Right) == 0) {
        bitbot.move(BBMotor.Left, BBDirection.Reverse, 40)
        bitbot.move(BBMotor.Right, BBDirection.Forward, 100)
    } else if (bitbot.readLine(BBLineSensor.Left) == 0 && bitbot.readLine(BBLineSensor.Right) == 1) {
        bitbot.move(BBMotor.Left, BBDirection.Forward, 100)
        bitbot.move(BBMotor.Right, BBDirection.Reverse, 40)
    } else if (bitbot.readLine(BBLineSensor.Left) == 1 && bitbot.readLine(BBLineSensor.Right) == 1) {
        bitbot.move(BBMotor.Left, BBDirection.Forward, 20)
    } else {
        bitbot.stop(BBStopMode.Coast)
    }
})

Løsniningsforslag JavaScript

Avsender

radio.setGroup(1)
basic.forever(function () {
    if (input.rotation(Rotation.Pitch) < -20) {
        radio.sendString("FRAM")
    } else if (input.rotation(Rotation.Pitch) > 20) {
        radio.sendString("RYGG")
    } else if (input.rotation(Rotation.Roll) < -20) {
        radio.sendString("VENSTRE")
    } else if (input.rotation(Rotation.Roll) > 20) {
        radio.sendString("HØYRE")
    } else {
        radio.sendString("STOPP")
        basic.pause(500)
    }
})

Mottaker

radio.setGroup(1)
radio.onReceivedString(function (receivedString) {
    if (receivedString == "FRAM") {
        bitbot.go(BBDirection.Forward, 60)
    } else if (receivedString == "RYGG") {
        bitbot.go(BBDirection.Reverse, 40)
    } else if (receivedString == "VENSTRE") {
        bitbot.rotate(BBRobotDirection.Left, 40)
    } else if (receivedString == "HØYRE") {
        bitbot.rotate(BBRobotDirection.Right, 40)
    } else {
        bitbot.stop(BBStopMode.Brake)
    }
})
